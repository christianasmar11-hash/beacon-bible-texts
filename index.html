Beacon Bible texts

Public-domain and openly licensed Bible texts as static JSON, for personal use in Beacon Bible. This page is a file index, not a reader.

index.json · books.json · LICENSES.md

Each translation is a folder of book files. Book 43 is John, for example KJV/43.json.
